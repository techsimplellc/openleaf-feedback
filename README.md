# openleaf feedback

Bug reports and feature requests for [openleaf](https://getopenleaf.com), the browser-based Markdown editor.

openleaf's source code is not public. This repository holds only issues.

- [Report a bug](https://github.com/techsimplellc/openleaf-feedback/issues/new?template=bug_report.yml)
- [Request a feature](https://github.com/techsimplellc/openleaf-feedback/issues/new?template=feature_request.yml)

You can also reach both from **Help** in the app.

**Everything posted here is public.** Don't paste private document content, file paths or personal details into an issue. If a bug needs a document to reproduce, cut it down to a small sample that shows the problem.

Before opening an issue, search the [existing issues](https://github.com/techsimplellc/openleaf-feedback/issues) to see if it's already been reported.
